# 六种报告体裁与图型选择（从本地历史报告归纳）

同一个事件在不同阶段要交的不是同一份文件。体裁选错，内容再全也会被打回。
先认体裁，再套骨架；骨架里的章节顺序照抄，不要按自己的逻辑重排。

病种层面的潜伏期、隔离期、结案判定、必做图，查 `templates/disease_profiles.yaml`，此处不重复。

## 1. 初次（初步）调查报告 —— 暴发/聚集性，2 例以上

一、基本情况（机构：地址、班级数、学生/教工数、住宿与供餐、卫生与通风）
二、疫情概况（病例定义 → 病例搜索方法 → 发病概况：三间分布前的总数、罹患率、重症死亡）
三、流行病学调查（首发病例 → 时间分布 → 班级/单位分布 → 人群分布 → 流行病学史）
四、实验室检测
五、调查判断（疫情性质、事件级别、是否达突发标准、网报时间、风险研判）
六、已采取的预防控制措施
七、下一步工作

要点：**病例定义必须写，且要带上追溯起点日期**（“自 X 月 X 日起，该校学生中……”），
这是后续能否结案的依据；病例搜索要写清四条渠道（晨午检与缺勤登记、访谈校医与班主任、
辖区医疗机构门诊住院记录、大疫情网直报检索）。

## 2. 进程报告（第 N 期）—— 篇幅短，只写变化

一、疫情进展（累计、新增、罹患率、痊愈与在管数）
二、病例发病及转归
三、密切接触者医学观察
四、预防控制措施落实情况（逐条对应上期措施，带量化数据）
五、存在问题与风险研判
六、下一步工作建议

要点：同一事件会有十几到二十几期，**每期只写增量与措施落实证据**（消毒面积、应种实种、
缺勤恢复），不要每期重写背景；措施部分要“上期说了什么 → 这期做到哪一步”。

## 3. 结案调查报告 —— 十节，是评审看的那一份

一、基本情况　二、调查方法（病例定义 + 病例搜索方法）　三、疫情概况（发病概况 + 临床特征）
四、流行病学特征（首例 / 时间 / 班级或地区 / 人群 / 流行病学史）　五、实验室检测
六、病因假设和风险研判　七、控制措施及效果评价（单位措施 / 疾控与医疗机构措施 / 效果评价）
八、存在问题、经验总结和建议　九、经济损失及成本效益分析　十、结案

要点：
- 第七节必须分“事发单位做的”和“疾控/医疗机构做的”两块，评审就是看责任是否说清。
- 第九节是硬指标，照国家《突发公共卫生事件经济损失评估测算表（试行）》分项：
  直接损失 = 应急处置费用（指挥协调、医疗救治、疾病预防控制、卫生监督、其他部门）+ 财产损失 + 善后处理；
  间接损失 = 经济贸易损失 + 专项科研 + 环境污染处置 + 其他。**只写一个总数会被要求返工**。
- 第十节写结案依据：末例发病/隔离日期 + 经过一个最长潜伏期 + 全部痊愈 + 终末消毒完成 + 谁批准的。

## 4. 结案申请单 —— 一页纸，报上级疾控

抬头「<区县>疾病预防控制中心突发公共卫生事件及相关信息结案申请单」，收件方固定为市级疾控。
正文一句话讲完五要素：**网报时间 → 事件名称与级别 → 末例发病（及隔离）日期 → 经过 1 个最长潜伏期
（写出天数）无新发 → 申请结案**。落款：申请人、审核人（手签）、单位、日期。

要点：不写调查过程、不写措施、不附图表。单例事件（霍乱等）可把“无新发病例”换成
“传播危险因素已清除、疫情得到有效控制”。医疗机构的签字栏不要代填。

## 5. 单例病例流行病学调查报告 —— 输入性 / 罕见 / 甲类

一、病例基本情况（姓名、性别、年龄、职业、证件号后四位、现住址、电话、户籍、工作单位）
二、发病及就诊经过（首发症状与日期、就诊机构与日期、诊断日期与类型、住院隔离、转归）
三、流行病学史（发病前最长潜伏期内的旅居史：国家/省市/日期/航班车次；接触史；职业暴露；
　　　　　　　　　饮食饮水与媒介叮咬史）
四、接触者调查和管理　五、实验室检测　六、感染来源研判　七、已采取的措施　八、下一步工作

要点：第三节按**天**回溯，写到具体航班/车次/餐厅/摊位的名称与时间；来源研判要给两种以上可能
并说明证据强弱（本地感染 vs 输入继发），不要一句“来源不明”收尾。

## 6. 报省/报政府的处置情况报告 —— 三节，最短

一、病例情况　二、处置情况　三、下一步工作措施。

要点：给上级看的版本，**只留结论、动作、请求**；数据用“截至 X 日 X 时”锁定，不放过程推演。
同一事件往往同时要交第 3 节那份十节报告和第 6 节这份短报告，内容口径必须一致。

## 图型选择

按“病种 × 数据条件”选，不按美观选。最小集永远包含流行曲线。

| 图 | 触发条件 | 作图规矩 |
| --- | --- | --- |
| 流行曲线 | 有 ≥2 例且至少一个有发病日期 | 柱状，**不用折线**；时间间隔取最长潜伏期的 1/4~1/3；诺如这类短潜伏期按 4~8 小时分箱，并在图注写清“以首例为起点向前推一个最长潜伏期” |
| 班级/单元分布 | 有事例的班级字段 | 柱状 + 副轴罹患率曲线；表里要有班级人数作分母，没有分母就只报例数，不要假算率 |
| 年龄性别分布 | 有个案出生日期或年龄 | 左右分侧条形；5 岁分组，人数少时合并到 10 岁 |
| 传播链示意 | 有明确接触关系且病例 ≤30 | 按代际分层，**实线=时间与接触史都支持，虚线=可能或待核实**，图注必须说明哪种算不确定 |
| 代际分布 | 有多代且不缺发病日期 | 只由发病时间结构推算，标出分代阈值；接触史缺失时明说“按时间推算” |
| 地理分布 | 有街道级及以上地址，或水源性/食源性/输入性 | 无合法底图时用场所聚合条形图或经纬度散点，**对外不得称 GIS 专题图** |
| 潜伏期分布 | 食源性疾病，有共同餐次时间 | 直方图 + 中位数/均数竖线；这是推断病原的关键图 |
| 病例-对照 OR | 做了病例对照 | 森林图，对数横轴，1 处画虚线；OR 与 P 都要标 |
| 采样与检测 | 有环境/食品/水源采样份数与阳性数 | 堆叠条形，标“阳性/总数” |
| 关键时间节点 | 单例病例报告 | 横向时间轴：发病→就诊→确诊→隔离→出院 |

降级原则：数据不够时**宁可少画一张，也不画一张会误导的图**；正文相应句子改为文字描述，
不要留“见图 X”却无图。
