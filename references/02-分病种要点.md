# 分病种要点：同一套骨架，重点说什么不一样

数据层在 `templates/disease_profiles.yaml`（12 个病种：潜伏期、隔离期、病例定义骨架、必问暴露、
必做图、暴发阈值、结案句）。本文件讲的是**写的时候把笔墨放在哪里**——这是模板给不了的部分。

## 用法

```python
import epi_core as core
p = core.get_profile("诺如")          # 别名模糊匹配
p["latent_max_days"]                  # 3
p["closure_rule"]                     # 结案判定句，可直接进报告
p["key_exposures"]                    # 必问暴露清单，进"流行病学史"
```

新增病种：往 YAML 里加一节即可，不用改代码。`verify: true` 表示该数值**没有**从本地语料核实过，
用前必须核对当期防控方案（伤寒、登革热、发热伴、食源性、基孔的潜伏期为指南值，标了 verify）。

## 呼吸道／接触传播（水痘、流感、手足口）

**笔墨重点**：场所结构。教室、宿舍、食堂、走廊、卫生间的接触机会差异，是解释"为什么这个班多"
的唯一抓手。要写到宿舍号、楼层、是否混班上课、是否错峰就餐。

**水痘特有**：必然出现多代（潜伏期长、可带毒上课）。要正面解释多代原因，语料里的四条标准解释是
①呼吸道+接触双途径难切断 ②应急接种率低未形成屏障 ③因学业未停课 ④晨午检质量不高、带病上课。
四选二三，配上自己的数据（接种率 20.50%、消毒面积、缺勤数），比空说"措施不到位"有力得多。

**手足口特有**：疱疹性咽峡炎要与手足口併提（同一病原谱）；关班口径写清"1个班停课10天"；
玩具、毛巾、餐具的消毒要写浓度与方式，不能只写"加强消毒"。

**流感特有**：用"流感样病例"定义（发热≥38℃+咳嗽或咽痛之一），不要把"感冒"写进去；
写疫苗接种率、发病班级相对隔离观察天数。

## 消化道／水源食源性（诺如、霍乱、伤寒副伤寒、其他感染性腹泻、食源性）

**笔墨重点**：时间精度与共同暴露。诺如潜伏期 12–72 小时，流行曲线**必须按小时分箱**（4–8 小时），
按天画会把双峰抹平。语料的原话是"以首发病例为起点，向前推一个最长潜伏期3天，以6小时为间隔"。

**诺如特有**：呕吐物气溶胶是主要传播方式之一，要写呕吐地点、处置方式（掩闭覆盖→消毒→清理）；
食堂从业人员带菌筛查与健康证；二次供水/直饮水排查。

**霍乱特有**：甲类，2 小时内网报，时限是硬约束。正文按日逐条写活动轨迹（语料范本是
「（一）8月8日　（二）8月9日……」逐日排），米泔水样便、无痛性腹泻是特征性描述；
要写 CTX 毒素检测、水产品与流动摊贩暴露、疫点划定与终末消毒。

**伤寒特有**：这一类的报告是"调查论文"级别的，必须上**病例对照**（OR 值+95%CI+P）与
**卫生学调查**（菜场摊位、灌溉水源、旱厕距离）。语料范本给出了分层分析的写法：
按购买地点分层（超市=参考组），新桥菜市场 OR 5.39（2.99–9.74）。溯源要落到地理坐标
（N31°48'29'', E120°29'26''）和污染路径（旱厕→水渠→池塘→蔬菜）。

**食源性特有**：潜伏期直方图 + 平均潜伏期（如 13.5 小时）+ 逐菜罹患率表 + 加工环节温度时间链；
对照要选"同餐未发病者"，不能选没吃饭的人。

## 媒介／动物源性（登革热、基孔肯雅热、发热伴）

**笔墨重点**：输入证据与媒介条件两件事。

**登革热／基孔**：发病前 14 天（基孔 12 天）旅居史要写到国家、城市、日期、航班号、同行人员；
本地传播风险靠**布雷图指数**与蚊媒密度说，不靠形容词；防蚊隔离写"至发病后 5 天（病毒血症期结束）"。

**发热伴**：蜱叮咬史常被否认，语料的标准处理是"患者否认蜱虫叮咬史，但近期未接触同类病例、
未接触不明原因死亡动物，综合判断由蜱虫叮咬发病的可能性大"——**用排除法支撑结论**；
实验室要写白细胞/血小板下降趋势与 SFTS 核酸检测；人传人风险要提"接触病例血液体液"。

## 人畜共患与特殊传播（猴痘、禽流感）

**猴痘**：21 天潜伏期、皮疹分期（斑疹→丘疹→水疱→脓疱→结痂）要写全；传播链图是核心图
（语料有"5例猴痘病例传播链分析图"），每一代都要有接触事实支撑；性接触史脱敏写（见文风库第 8 节）；
分型（分支 Ia/Ib/II）必须写，输入来源要写清"境外或外省，正在协查"。

**禽流感（H5N6 等环境阳性）**：这是"事件"不是"疫情"，报告体裁是**调查处置意见**而非流调报告；
核心是风险判定（人有没有症状、环境阳性点位）与处置措施（扑杀、无害化、终末消杀、7 天健康监测）。
语料范本的措辞：「仅鸡蛋表面涂抹标本检出 H5N6 型禽流感病毒核酸阳性（CT值：29），其余标本均为阴性」。

## 新发／输入性单例（通用）

单例报告不写"三间分布"（没有分布可言），改走八节：基本情况→发病就诊经过→流行病学史→
接触者调查和管理→实验室检测→感染来源研判→已采取的措施→下一步工作。
"感染来源研判"是这一体裁的灵魂，要给出**输入 vs 本地**的明确判断与依据（旅居史+基因型+时间窗），
不能只罗列事实不下结论。

## 三家容易写混的边界

| 易混 | 判据 |
|---|---|
| 暴发 vs 聚集性 | 达到病种暴发阈值（水痘1周≥10例、诺如7天≥20例、手足口1周≥10例）为暴发；未达阈值为聚集性 |
| 突发公共卫生事件 vs 一般疫情 | 达《国家突发公共卫生事件应急预案》分级标准才网报；未达标准只做疫情处置，报告体裁为调查报告而非突发事件报告 |
| 结案 vs 疫情平息 | 结案需要"末例+一个最长潜伏期+无新发+痊愈+消毒完成"；疫情平息只是发病数降下来 |
