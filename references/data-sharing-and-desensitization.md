# 流调材料脱敏与外发

流调材料天生带个人健康信息。只要它会离开单位（给同事、进仓库、当教学示例、发推文），
就先走一遍本文件。判定口径一句话：**按名字能把人找出来吗？能，就不能发。**

## 一、字段分级

| 处理 | 字段 |
|---|---|
| 必删 | 患者姓名、家长姓名、有效证件号、联系电话/手机、门牌号与详细住址、出生日期（年月日）、填卡医生、报告人姓名与手机 |
| 可留（统计所需） | 性别、年龄（年岁）、班级/年级、人群分类、发病日期、诊断日期、病例类型、疾病病种、现住址类型（本县区/本市其他县区…） |
| 需泛化 | 机构名（学校/幼儿园/单位）、乡镇街道、具体社区村名、社区卫生服务中心名 |

泛化写法：机构 → 「某高级中学」「某实验学校」「某幼儿园」；地名 → 「某镇」「某社区某村」；
保留市/区级地名通常无妨（报告需要地域背景），但**校名 + 班级 + 日期 + 病例数**组合已足以定位一场疫情，一律泛化。

## 二、大疫情网个案表怎么处理

导出的 CSV 常见是 **GBK/GB18030**，直接按 UTF-8 读会抛 `UnicodeDecodeError: invalid continuation byte`。
按 `gbk` → `gb18030` → `utf-8-sig` 顺序试解码。

典型列：`患者姓名 性别 单位 详细住址 现住地址 人群分类 病例类型 疾病病种 发病日期 诊断日期 家长姓名 出生日期 有效证件号 现住址类型`。

重建成一张只含统计字段的表，行号化名：

```csv
病例编号,性别,年龄,单位,人群分类,发病日期,诊断日期,病例类型,疾病病种,现住址类型
C01,男,9,三（5）班,学生,2016-05-05,2016-05-06,临床诊断病例,水痘,本县区
```

- 年龄由 `出生日期` 与 `发病日期` 算（跨生日要减 1），不要直接抄 `出生日期`。
- `单位` 剥掉校名前缀再留着（`无锡市XX区某实验学校二4班` → `二（4）班`）；正则只锚定开头会漏掉带区名的写法，
  剥完检查一遍还有没有残留的校名。
- 病例编号仍然在，流行病学结构一点没丢；图与统计结果不变，可以宣称“与原始 N 例口径一致”。

事件 YAML 里同类字段一起改：首例描述里的姓名→`某`、电话→`（略）`、住址→`某社区某村`、
出生日期直接删（只留年龄）、报告人/审核人→`（略）`、机构与卫生院名泛化。

## 三、扫一遍（改完立刻做）

```bash
grep -rInE '1[3-9][0-9]{9}|0[0-9]{2,3}-[0-9]{7,8}|[0-9]{17}[0-9Xx]|/Users/[a-z]+|<真实校名>|<真实人名>' \
  --exclude-dir=vendor --exclude='*.pdf' .
```

命中类型按上表处置。两条容易误判：

- **字段名不是数据**：`"家长姓名": "guardian"` 这类解析映射留著，它不泄任何东西。
- **目录名也是泄露面**：`examples/02-<真实校名>…/` 这样的路径会把校名带进仓库树和每一条日志，一并改名。

## 四、必须重新生成，再扫一遍产物

docx/pdf/md 里是**渲染时的文本**，改了 YAML 与 CSV 不动产物，旧名字还在里面。流程是：

1. 改源（YAML / CSV）
2. 重跑生成，覆盖旧产物
3. 对**产物**再扫：`pdftotext -enc UTF-8 输出.pdf - | grep -nE '<上面那串模式>'`
4. 图片里如果压了文字（截图类）无法用 pdftotext 发现，只能换图或重画

只扫 `.md` 不扫 `.pdf` 是常见漏洞——同一句话在 PDF 里可能就是没清掉的那一版。
