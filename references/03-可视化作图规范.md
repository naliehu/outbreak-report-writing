# 可视化作图规范：什么数据画什么图，画到什么程度

两套图各管一段：引擎的 `vendor/flowfig` 出**四张叙事图**（传播链、代际、地理、流行曲线），
`scripts/epi_viz.py` 出**统计图**（13 种，用于三间分布与专题分析）。同一份报告里不要重复画同一个内容。

## 1. 决策表

| 图 | 需要的字段 | 触发条件 | 用哪个模块 |
|---|---|---|---|
| 流行曲线 | 逐例发病日期 | ≥3 例且有日期 | flowfig / `epi_viz.epicurve` |
| 班级（单元）分布 | 班级字段或班级计数 | ≥2 个班有病例 | `epi_viz.group_bar` |
| 年龄性别 | 年龄+性别 | ≥5 例 | `epi_viz.age_sex` |
| 代际 | 发病日期+常见潜伏期 | 推算≥2 代且≤8 代 | flowfig / `epi_viz.generation_steps` |
| 传播链 | 病例间接触关系 | ≤30 例且有关系记录 | flowfig / `epi_viz.transmission_chain` |
| 地理分布 | 村/社区名 或 经纬度 | 跨村/社区，或水源食源性 | flowfig（场所卡片）／`epi_viz.geo_dist` |
| 潜伏期直方图 | 进食时间+发病时间 | 单次共同暴露（食源性） | `epi_viz.latent_hist` |
| 症状构成 | 症状清单 | 有 ≥3 类症状 | `epi_viz.symptom_bar` |
| 采样结果 | 各类采样份数与阳性数 | 有环境/食品/水源采样 | `epi_viz.env_sampling` |
| 病例对照 OR | OR+95%CI+P | 做过病例对照 | `epi_viz.case_control_forest` |
| 单例时间轴 | 发病/就诊/确诊/隔离/出院 | 单例报告 | `epi_viz.case_timeline` |
| 应急接种进度 | 日期+累计接种 | 开展应急接种且≥2 个时点 | `epi_viz.vax_curve` |
| 楼层/区域分布 | 楼层+病例数+人数 | 宿舍或分楼层传播 | `epi_viz.floor_map` |

**没有数据就不画**，并在正文写原因（"未取得逐例发病日期明细，故未绘制流行曲线"）。
拿汇总数据硬凑一张曲线是造假，不是降级。

## 2. 流行曲线的七条硬规范

1. **柱状，不给折线。** 折线暗示连续变化，发病数是离散计数。
2. **间隔取最长潜伏期的 1/4～1/3**，且使柱数落在 8–35 之间。诺如（3天）→ 4–8 小时；水痘（21天）→ 5–7 天；
   食源性（数小时）→ 1 小时。
3. **起点可以前推一个潜伏期**。语料做法："以首发病例为起点，向前推一个最长潜伏期，以6小时为间隔"，
   这样能看出暴露早于首例报告。
4. **标注首例与末例**（贴柱顶，小字灰色）。
5. **干预时点画竖虚线**：停课、终末消毒、应急接种启动、放假。文字标在线上方，不要压在柱子上。
6. **尾部零值柱裁掉**，只留 1–2 个，避免右侧一片空白。
7. **双峰要解释**。出现两个间隔约一个潜伏期的峰，正文必须写一句"各发病高峰间相差约一个常见潜伏期"，
   这是代际推断的直接证据。

## 3. 图注写法

格式：`图N　<机构或地区><病种><内容>`，例如：

```
图1　某高级中学水痘暴发疫情病例发病时间分布
图2　某高级中学水痘暴发疫情病例年龄性别分布
图3　5例猴痘病例传播链分析图
```

规矩：图注在图的**下方**、居中、加粗小五；正文引用写"见图1"或"详见图2"，不写"如下图"。
表题注在表的**上方**（`表1　……`）。图表编号全文连续，附录图表另起编号（附表1／附图1）。

## 4. 传播链图的诚实性

- **实线**：时间窗（潜伏期）+ 接触事实都支持。
- **虚线**：仅时间窗支持、或接触史来自单方口述、或存在替代来源。
- 图注必须写一句判定规则，例如"实线：时间与接触史均支持；虚线：可能或待核实"。
- 节点写姓名（或化名）+ 发病日 + 诊断类型；边上写接触日期与方式（同住、同餐、性接触）。
- **不要把首例画成源头**。上游若有"另有暴露可能"，画一个虚线指向图外的"待查来源"，比焊死链条安全。

## 5. 地理分布的边界

- 没有合法行政区底图时，只做两种图：**村/社区聚合条形图**（横向 lollipop）或**经纬度气泡示意图**。
- 图注必须写"示意，非实际边界底图"。
- 水源性/食源性事件要在地图上标出**污染源点位**（菜场、水井、池塘、加工厂），并在正文给出坐标或距离。

## 6. 排版与导出

- 300 dpi PNG，物理宽度 15.2 cm（A4 正文宽），纵向长图不超过 11 cm。
- 中文用宋体（Songti SC），字号：标题 11 pt 加粗，轴标签 9 pt，刻度 7.5–8 pt，图注 7 pt。
- **字体必须在模块导入时设 rcParams**——在绘图函数里设不生效（Text 对象创建时已固化字体），
  表现为"字体装了还是方框"。
- 无网格线、无渐变、无阴影、无 3D；只留左、下轴线；颜色不超过 3 种（深蓝主色 + 灰 + 红强调）。
- 导出 docx 时按宽高比自动定宽，避免拉伸；图与图注不跨页。

## 7. 常见错误

| 错误 | 后果 |
|---|---|
| 用折线画流行曲线 | 被质疑"数据是连续的？" |
| 间隔按天画诺如 | 双峰消失，看不出点源暴露 |
| 传播链全画实线 | 一经追问即崩，属过度推断 |
| 图注缺机构名 | 多图汇编时无法区分 |
| 地理图标了实际行政边界但无来源 | 涉嫌使用无审图号地图 |
| 同一报告里"图1"出现两次 | 汇编、评审直接扣分 |
