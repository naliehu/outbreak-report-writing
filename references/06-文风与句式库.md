# 文风与句式库（从 477 份真实报告统计得出）

统计口径：本地语料 1308 份可提取文本中，标题含「初步调查报告／初次报告／结案报告／进程报告／调查报告」
的 **477 份**报告类文稿，合计约 333 万字、16815 句。以下所有数字都是实测值，不是经验之谈。

用途：写的时候不必"模仿风格"，把这份文件当**参数表**用——句长按中位数走，功能句按定式填，
不确定性按等级说话，数字按六条规则摆。写完拿第 10 节自检。

---

## 1. 句法节奏：长句、多逗号、分号并列

| 指标 | 实测 | 怎么用 |
|---|---|---|
| 平均句长 | **60.7 字** | 一个环节一句话，允许长 |
| 句长中位数 | **48 字** | 一半的句子在 48 字以内，别全写长 |
| 90 分位 | **115 字** | 陈述完整过程（发病→就诊→诊断→隔离）时到这个长度是正常的 |
| 逗号密度 | **238 个/万字** | 平均每 42 字一个逗号；顺叙过程靠逗号推进 |
| 分号密度 | **14.5 个/万字** | 并列要素（症状、措施、来源、分项）用分号分层 |

**反面**：短句成串（"患者发热。患者就诊。患者确诊。"）读起来像口供，不像报告。
**正确**：一件事一口气说完，用逗号推进，用分号并列。

> 原文例（洛社结案，68 字）：
> 该学生于3月11日出现发热（热峰38℃）和腰背部疱疹症状。调查该生无水痘疫苗接种史，自述发病前3周内无外出史，无水痘病例接触史。

注意第二句：三个并列要素用逗号而非分号——**同一主语的三项用逗号，不同主体的并列才用分号**。

> 分号例（伤寒结案）：
> 92例病例中男性42例，女性50例，男女比例0.84:1；户籍地为本地65例、外地25例；职业分布工人54例、农民10例……

这就是分号的标准用法：**人群特征的三个维度，每维度一句，分号隔开**。

## 2. 高频体例词：这些不是废话

每万字出现次数（477 份实测）：

| 词 | 频次 | 用法 |
|---|---|---|
| 目前 | 4.5 | 描述当前状态："目前所有病例均已居家隔离" |
| 进一步 | 3.2 | 后续动作："进一步排查接触人员""有待进一步协查验证" |
| 同时 | 3.0 | 并行措施："同时开展外环境采样" |
| 截至 | 1.9 | 数据截止："截至3月26日16时，共报告37例" |
| 现将 | 1.9 | 转承："现将调查处理情况报告如下" |
| 报告如下 | 1.8 | 段落收尾，几乎每篇首段都有 |
| 针对 | 1.4 | 措施指向："针对涉疫班级开展应急接种" |
| 接报后 | 1.0 | 时间推进的锚点 |
| 结合 | 0.9 | 研判起句："结合流行病学调查、临床表现及实验室检测结果" |
| 均已／均未 | 0.8／0.4 | 全称判断，省掉"全部" |
| 未见／未发现 | 0.5／0.3 | 阴性发现，比"没有"更规范 |

**别删这些词**。它们是公文体裁的黏合剂，删了会变成简报体。但也别整段堆——一段里两三个足够。

## 3. 七种功能句的定式

### 3.1 开篇（接报句）

语料中 79% 的首句是「日期 + 时刻 + 逗号」起头，四种常见精度：

```
2026年3月26日8时许，新吴区疾控中心接新吴实验小学校医报告：近日学校有多名学生出现恶心、呕吐、腹痛、腹泻等症状。
2026年4月20日11时40分，惠山区疾控中心急传科接惠山区洛社镇卫生院预防保健科电话报告：……
2016年6月3日11：07，某实验学校保健老师报告全校一周内发生12例水痘病例。
2026年5月8日12时，无锡市滨湖区疾控中心接到无锡市滨湖实验幼儿园报告：……
```

**骨架**：`<日期><时刻>，<接报单位>接<报告人／机构>报告[：]，<一句话说清发生了什么、多少例>。接报后，<我方动作：组织人员赶赴现场开展流调、采样、指导>。`

三种接报渠道要写清：电话报告（最常见）、系统预警（因病缺课／症状监测）、医疗机构报告。这决定了后面"核实"环节的写法。

### 3.2 核实与升级

```
接报后，中心立即进行核实，并及时将初步核实情况报告无锡市疾控中心及区民政卫健局。
经核实，截至6月3日11：10，全校一周内共有12例水痘病例。
经初步核实，4月20日12:30确认为一起学校水痘暴发疫情（一周内发病已超10例），立即上报区卫生健康委和市疾控中心，并于4月20日13:28在"突发公共卫生事件管理信息系统"中进行网络直报。
```

**要素固定**：核实时间 → 核实结论（是否达暴发／突发标准，附判据）→ 上报对象 → 网报时间（精确到分）。

### 3.3 分布描述（三间分布）

时间：
```
本次疫情自2026年3月11日首例病例发病开始，截止2026年5月31日末例病例发病，该学校陆续报告水痘病例共49例，罹患率为1.44%。
从图1中可以看出，本次疫情持续时间较长，共有3个发病高峰，自最后1个高峰发病数降至1例以后，5月19日至5月31日共发病3例。
```

班级／地区：
```
49例病例涉及3个年级13个班级，主要集中在高二年级（46例）。其中：高二14班发病数最多为13例，班级学生罹患率为24.07%，其次为高二7班9例，为16.98%，第三为高二11班6例，为11.76%，其余班级发病数在5例及以下。
```

**定式**：总数 → 分布范围 → 前三名（各带例数+罹患率）→ 其余概括。**永远给前三名，不给全名单**（全名单进表）。

人群：
```
92例病例中男性42例，女性50例，男女比例0.84:1；户籍地为本地65例、外地25例；职业分布工人54例……
49例病例中男性报告发病36例，女性报告发病13例，男：女=2.80:1。主要集中在17岁（32例），占总发病数的65.31%。
```

### 3.4 实验室

```
共采集病例标本9份、对照肛拭子10份、环境样本5份送检，结果显示：5份病例标本诺如病毒II型核酸阳性。
对21株沙门伤寒菌进行PFGE分型，其中14株为本次疫情患者分离的菌株……13株带型一致，同源性较高，可确认本次是由一种型别的病原菌引起的伤寒局部流行。
此次疫情未采集病例标本进行水痘-带状疱疹病毒核酸检测。
```

**第三句是关键**：没做检测就直说"未采集"，并交代诊断依据（临床表现+流行病学史）。**不许沉默跳过**，也不许写"未做相关检测"含糊过去。

### 3.5 研判（按证据强度分级，见第 6 节）

```
根据流行病学分布特征、临床症状、实验室检测结果，判定本次疫情为一起学校水痘暴发疫情。
根据流行病学分析、实验室伤寒沙门菌培养及PFGE检测结果，初步判断这是一起局部地区的伤寒流行，存在同一优势菌群。
综合流行病学、卫生学调查，排除本起疫情为自来水污染引发，重点指向被污染的食品，特别是新桥农贸市场。
```

**注意第三个例子的写法**：先"排除"再"指向"，排除项要写明依据（自来水无病例聚集），指向项要落到具体场所。

### 3.6 措施（动词起句，见第 5 节）

```
1.严格落实病例管理及复课。学校每日开展晨午晚检，落实因病缺课缺勤病因追查制度，在校学生/教职员工如出现发热、皮疹等水痘疑似症状，及时隔离直至离校，指导其及时就诊并居家隔离治疗，至水痘疱疹全部干燥结痂为止（不少于发病后14天），至现住址所在地社区卫生服务中心开具复工/复课证明，方可返校。
```

**每条措施的三个必备件**：动作（严格落实）→ 对象（病例管理及复课）→ 可核查的量化口径（不少于14天、凭证明返校）。缺第三个的就是空话。

### 3.7 结案

```
鉴于距离最后一例病例有效隔离后经过一个最长潜伏期（21天）无新发病例，且所有病例均已痊愈复课，经区专家讨论，该起疫情可结案。
鉴于江阴市新桥镇最后一例伤寒病例发病日期为9月25日，现经过一个最长潜伏期已无新发病例报告，所有病例均康复并符合解除隔离标准，病家、隔离病房等相关污染场所均已开展终末消毒，可以认定本次伤寒流行疫情已得到有效控制、达到结案标准。
```

**五要素**：末例日期 → 观察时长（写出天数）→ 无新发 → 病例转归 → 消毒／批准。一页纸的结案申请单就是这段话压缩成一句。

## 4. 数字严谨性六条

1. **率必带分母**：`罹患率1.44%（49/3408）`。实测语料中大量写作「罹患率X%（分子/分母）」，这是行业惯例，照做。
2. **构成必带占比**：`发热29例，占报告病例总数的59.18%`。频率最高的三种说法：占报告病例总数的／占发病总数的／占总报告病例数的——选一种，全篇统一。
3. **性别比两种写法择一**：`男女性别比为2.80:1` 或 `男36例、女13例`。同一篇里如果先写 36:13 后写 2.80:1，会被追问是不是两批人。
4. **分子分母同源同日**：罹患率的分母是「该校学生+教职工总数」，不是仅学生；班级罹患率的分母是该班人数。分子取哪一天的数据，分母就取哪一天。
5. **小数位统一**：率与占比保留 2 位（1.44%、59.18%、24.07%）；OR 保留 2 位；损失金额到元或万元，全篇统一。
6. **不写无出处的绝对值**：`消毒面积约8万平方米`、`共接种1628针次`——这类只能来自现场记录，不能估算后写确数；估算要加"约"。

## 5. 措施句的动词层级

实测措施句开头动词频次：**加强 431 > 开展 128 > 密切 109 > 进一步 60 > 严格 52 > 强化 48 > 严格落实 48 > 做好 41**。

分三类用：

| 类别 | 动词 | 用在哪 |
|---|---|---|
| 压实责任 | 严格落实、严格、强化、督促、规范 | 病例管理、复课证明、预检分诊、监督执法 |
| 推进动作 | 开展、组织、建立、完善、落实 | 流调、采样、消毒、接种、培训、宣教 |
| 持续状态 | 加强、密切、持续、每日 | 监测、追踪、零报告、通风消毒 |

**不要连用三个"加强"**。一段措施里"加强"最多出现一次，其余换"落实""开展""督促"。

## 6. 不确定性的四级表达（最容易被扣分的地方）

| 证据 | 句式 | 例句 |
|---|---|---|
| 病原+流行病学+临床三方吻合 | 判定为／综合判断为 | 判定本次疫情为一起学校水痘暴发疫情 |
| 链条成立但源头未闭环 | 考虑为／可能性大 | 考虑为首例病例的二代病例；病例张保龙传播给陈志超的可能性大 |
| 存在替代解释 | 不排除……的可能 | 不排除社区内交叉感染的可能；不排除在江阴市、梁溪区感染的可能性 |
| 数据缺失 | 有待／尚需 | 具体病原体有待实验室检测结果；学生的卫生习惯及卫生意识有待加强 |

**铁律**：不要用"初步判断"当万能挡箭牌——语料里"初步判断"只出现在**已经有病原学或 PFGE 支持、但传播途径尚未完全闭环**的场合。三级证据配三级措辞，越级就是虚假确定性。

## 7. 时间严谨性

- 事件叙述精确到「时」，关键节点（接报、网报、隔离、末例）精确到「时／分」。
- 区间必须闭合：`发病前14天内`、`至疱疹全部结痂（不少于发病后14天）`、`经过一个最长潜伏期（21天）`——**写出天数**，别只写"一个潜伏期"。
- 观察期要写截止日：`至2026年8月24日无新发病例发生`。
- 潜伏期数据查 `templates/disease_profiles.yaml`，不要凭记忆写（伤寒 3–42 天、诺如 12–72 小时、猴痘 5–21 天差异极大）。

## 8. 病种措辞表（语料实测，直接抄）

| 病种 | 必须写到这个颗粒度 |
|---|---|
| 水痘 | 隔离至疱疹全部干燥结痂，不少于发病后14天；**凭现住址所在地社区卫生服务中心预防保健科出具的复课证明**方可返校；应急接种写明应种/实种/接种率 |
| 手足口病 | 关班／停课天数（1个班停课10天）；1000mg/L 含氯消毒剂擦拭或浸泡课椅、扶手、厕所；病例居家隔离2周，症状消失前不得复课 |
| 诺如 | 吐泻物及时掩闭覆盖、消毒清理；医学观察3天；做到"早发现、早隔离、早治疗"；症状消失后72小时复课 |
| 流感 | 居家隔离至热退后2天，杜绝带病上课；发病班级相对隔离上课观察至少7天 |
| 霍乱 | 甲类管理，2小时内网报；症状消失、连续2次（间隔≥24h）肛拭子核酸阴性解除隔离；密接医学观察5天 |
| 伤寒 | 落实疫点消毒、"三管一灭"、爱国卫生运动；血/便培养；PFGE 同源性；食品从业人员带菌筛查 |
| 登革热 | 防蚊隔离至发病后5天；布雷图指数；发病前14天境外／省外旅居史（写到国家、城市、航班） |
| 猴痘 | 隔离至皮疹完全结痂脱落、不少于21天；发病前21天性接触史（措辞需脱敏，见下） |
| 发热伴 | 蜱叮咬史与田间劳作史；白细胞/血小板减少；接触病例血液体液 |
| 食源性疾病 | 逐菜菜单、进食至发病时间差、平均潜伏期（如13.5小时）、生熟分开与储存温度 |

**猴痘类敏感暴露史的写法**（涉及隐私又不能漏）：写"发病前21天内有临时性伴接触史，具体接触时间与对象正在协查"，不写软件名称、昵称、房号。原始流调表另存，正文只用脱敏表述。

## 9. 禁止清单

| 不许写 | 改成 |
|---|---|
| 高度重视、迅速行动、全力以赴 | 删掉，直接写做了什么、几时做的 |
| 进一步加强防控工作 | 加强什么、谁执行、几时完成、怎么核查 |
| 疫情总体可控 | 给依据：末例日期+观察天数+二代病例数+缺勤恢复情况 |
| 经调查，情况基本清楚 | 删。说清哪几项清楚了、哪几项还没 |
| 部分病例、若干学校、多人 | 给准确数；确实无法确数就写"截至X时已核实N例，另有M例待核实" |
| 不详、待查（写在数据格子里） | 用〔待补P0-2〕标记 + 附录 A 说明谁来补、多急 |
| 患者、病人混用 | 全篇统一用"病例"（报告体），个案调查表可用"患者" |
| 该疫情 | 首现全称，之后用"本次疫情"或"该起疫情"，不混用 |

## 10. 交付前 12 问（拿着报告逐条念）

1. 首句有没有精确到时的接报叙述？报告人、报告单位、途径齐不齐？
2. 病灶机构的规模（班级数、学生数、教职工数）有没有？罹患率的分母是不是这个数？
3. 每个百分数后面有没有括号分母？全篇小数位一致吗？
4. 病例定义有没有写追溯起点日期（自X月X日起）？
5. 病例搜索写了几个渠道？四条（晨午检/访谈/医疗机构/大疫情网）齐不齐？
6. 首末例日期、发病高峰段写没写？图的间隔与潜伏期匹配吗？
7. 班级分布有没有前三名+罹患率？未归入班级的例数（教师、职工、失访）交代了吗？
8. 实验室段落：采样类型、份数、阳性数、方法齐不齐？没做检测有没有说明？
9. 研判句的证据等级对不对（判定／考虑／不排除／有待）？有没有越级？
10. 每条措施能不能被核查（天数、浓度、应种实种、消毒面积）？
11. 密接：判定标准、人数、观察天数、有无二代病例，四项齐不齐？
12. 结案：末例日期+最长潜伏期天数+无新发+痊愈+消毒+批准，六项齐不齐？经济损失分直接/间接了吗？

12 问全过，这份报告基本不会被退。任何一问答不上，就是附录 A 里的一个 P0。
